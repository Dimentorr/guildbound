# Guildbound 0.3.3-dev

- K → «Настройка HUD»: размер 75–175%, прозрачность фона 0–100%, шесть вариантов порядка HP/MP/SP. Настройки сохраняются локально, есть предпросмотр и сброс. Порядок полос — сверху вниз; свободного перетаскивания отдельных полос пока нет.
- Собственная полоса еды показывает ванильную сытость 0–20. «Вода» с прочерком — только заготовка жажды, без расхода и игровых эффектов.
- Ванильные полосы HP и еды скрываются только при отображении кастомного HUD. Воздух, броня и здоровье транспорта сохранены. Временное здоровье поглощения показано дополнительным числом рядом с HP.
- Карточка персонажа в главном окне уменьшена. Принятые задания помечаются «ПРИНЯТО». Подраздел заклинаний называется «Заговоры»; колесо боевых умений сохраняет своё название.
- Дорожки к доступным для покупки талантам жёлтые, к полностью изученным — зелёные. Недостающий уровень и недостаточная сумма очков выделяются красным.
- Экипировка призванной нежити определяется уровнем класса некроманта, независимо от ранга гильдии. Пороги брони: 10 кожа, 25 железо, 50 алмаз, 80 незерит, 100 зачарования IV. Меч: железный, с 35 алмазный, с 80 незеритовый. Объяснение перенесено в описание подкласса.

Проверка: 102 JUnit-теста; компиляция серверных сценариев; четыре серверные проверки с Terralith 2.5.8 (прогрессия, 30 активных умений, расширение/призыв, бой). Русская/английская локализации: 493 одинаковых ключа и совпадающие параметры. Графический клиент не проверялся.
